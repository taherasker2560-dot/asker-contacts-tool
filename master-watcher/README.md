# مراقب فارمافلاي (الماستر)

بيعمل حاجتين على الجهاز اللي عليه فارمافلاي:
1. **صندوق أسود:** بيصوّر الشاشة كل 3 ثواني (آخر 12 لقطة بس، مصغّرة، على الجهاز نفسه، مفيش رفع).
2. **تنبيه فوري** لما فارمافلاي يتهنج (Not Responding) أو يقع، أو الجهاز يتقفل فجأة. مع آخر لقطات قبل الحادثة = شكل الفاتورة اللي كانت مفتوحة.

لو التنبيه جه: افتح الدرج وراجع آخر بيعة، وشوف لقطات `incidents\<وقت>_<نوع>\`.

## تجربة (على اللاب)
```powershell
cd D:\path\to\master-watcher
.\watcher.ps1 -SelfTest      # لقطة وحادثة تجريبية: تأكد إن اللقطة بتظهر الشاشة
.\Test-Watcher.ps1           # تهنيج حقيقي لبرنامج وهمي (90 ثانية)، مش بيلمس فارمافلاي
```
لو `ExecutionPolicy` منعت: `powershell -ExecutionPolicy Bypass -File .\watcher.ps1 -SelfTest`

## تشغيل دايم
```powershell
.\watcher.ps1 -Install       # مهمة بتشتغل عند دخول المستخدم (لازم المستخدم يكون داخل، عشان اللقطات)
Start-ScheduledTask AskerMasterWatcher
.\watcher.ps1 -Uninstall
```

## التنبيه
`config.json` > `Alert`: صوت على الجهاز (افتراضي)، وتليجرام (`TelegramBotToken` + `TelegramChatId`)، أو `WebhookUrl` يستقبل JSON `{source,text,at}`.

## حدود
- مش بيقرا الأصناف نصيًا (OCR). اللقطات بتبيّن الفاتورة بالعين.
- بيعة اتفتحت واتلغت قبل الحفظ من غير تهنيج مش بيمسكها دلوقتي (المرحلة الجاية).
- لو الشاشة مقفولة (Lock) اللقطات بتفشل لحد ما تتفتح.
- اللقطات ممكن تظهر أسماء عملاء: فضلها على الجهاز، ومش بتتنقل.
