# النقل من نسخة فارمافلاي (الملف المضغوط)

الهدف: البرنامج الجديد يبدأ **كأنه شغال من 2018**: كل فاتورة بيع وشرا ومرتجع وتحصيل بتاريخها ورقمها، وأرصدته النهارده = فارمافلاي بالظبط.

## الخطوات
| | الخطوة | الأداة | بتطلع إيه |
|---|---|---|---|
| 1 | فك الضغط ولاقي النسخة (.bak) | `unpack.sh` | مكان النسخة وحجمها وبصمتها |
| 2 | استرجاع النسخة على SQL Server (Docker) | `restore.sh` | قاعدة `pf` للقراية بس |
| 3 | خريطة الجداول | `discover.py` | `discovery.md`: كل جدول، أعمدته، عدد صفوفه، أول وآخر تاريخ |
| 4 | نسخ كل الجداول لـ Postgres زي ما هي | `copy.py` | schema `pf_raw` + مقارنة عدد الصفوف لكل جدول |
| 5 | ربط جداول فارمافلاي بالشكل الموحّد | `pharmafly-to-stage.sql` (بيتكتب بعد خطوة 3) | schema `stage` |
| 6 | النقل بالتاريخ والمطابقة | `select ph.import_history('اسم النسخة');` | الملخص + `ph.import_issues` |

## التشغيل
```bash
pip install -r requirements.txt            # pymssql و psycopg
WORK=~/asker-import                        # برا المستودع: فيه داتا العملاء
bash unpack.sh   $WORK  /path/to/pharmafly-backup.zip
bash restore.sh  $WORK  $WORK/unpacked/…/xxx.bak
python3 discover.py $WORK                  # راجع $WORK/discovery.md
PGURL=postgresql://… python3 copy.py $WORK # القاعدة الجديدة (نسخة تجريبية الأول)
psql "$PGURL" -f pharmafly-to-stage.sql
psql "$PGURL" -c "select ph.import_history('pharmafly 2026-11-13');"
```

## فين يتعمل
- **على اللاب:** فيه النسخ أصلًا، والهَب بيرجّعها كل شوية. محتاج Docker (أو SQL Server اللي عليه) وPython.
- **هنا في الجلسة:** Docker وSQL Server شغالين وجربناهم. محتاج الملف يوصل هنا.
- الاتنين بيكتبوا في **نسخة تجريبية** من القاعدة الأول. الحقيقية بعد ما الأرقام تتطابق.

## الأمان
- النسخة فيها أسامي العملاء وأرقامهم ومشترياتهم: **ممنوع** تترفع على GitHub أو تتبعت لأي خدمة تانية. `unpack.sh` بيرفض فولدر شغل جوه المستودع.
- كلمة سر SQL Server بتتعمل لوحدها وبتتحفظ في `$WORK/mssql.env` بس.
- كل الأدوات بتقرا من فارمافلاي، ومابتكتبش فيه.
