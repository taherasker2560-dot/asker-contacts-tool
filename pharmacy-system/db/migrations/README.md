# تعديلات القاعدة (migrations)

بعد التسطيب الأول، **ملفات `db/00` لـ `db/13` ماتتعدلش**. أي تعديل في القاعدة = ملف جديد هنا.

## اسم الملف
`YYYYMMDDHHMM_اسم_قصير_بالإنجليزي.sql`، مثلًا `202611140930_item_shelf.sql`. الترتيب بالاسم = ترتيب التطبيق.

## القواعد
1. الملف بيتطبق **مرة واحدة في عملية واحدة**: يا كله يتطبق يا ولا حاجة. ماتكتبش `begin`/`commit` جواه.
2. **ماتعدّلش ملف اتطبق.** عايز تغيّر تاني؟ ملف جديد. (البصمة بتتسجل، والتحديث بيوقف لو ملف قديم اتغير.)
3. **مفيش مسح داتا** من غير موافقة المالك ونسخة قبلها. «نشيل حاجة» = نخفيها الأول، والمسح بعدين في ملف لوحده.
4. **الدفاتر والمستندات المرحّلة ماتتعدلش.** قاعدة حساب جديدة بتمشي على الجديد بس.
5. أول سطور الملف: **المطلوب، ليه، والرجوع** (الأوامر اللي ترجّع الحال زي ما كان).
6. التعديل لازم يكون معاه اختبار في `tests/` يثبت إنه شغال، وكل الاختبارات القديمة تعدّي.

## شكل الملف
```sql
-- 202611140930_item_shelf
-- المطلوب: مكان الصنف على الرف يظهر في البحث (طلب المالك 2026-11-14).
-- الرجوع: alter table ph.items drop column shelf;
alter table ph.items add column shelf text check (char_length(shelf) <= 20);
```
