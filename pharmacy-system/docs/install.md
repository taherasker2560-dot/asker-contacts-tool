# تسطيب البرنامج على كمبيوتر الصيدلية

> **دلوقتي:** التجربة على اللاب الأول ([`install/laptop/`](../install/laptop/README.md)). كمبيوتر الصيدلية بعد ما نجربه ونحسنه.

**الفكرة:** البرنامج والداتا على كمبيوتر الصيدلية زي فارمافلاي. مفيش رفع داتا لأي حتة. كل واحد بيدخل بيوزر: الموظفين بكلمة سر، والبوت بمفتاح.

## المكونات (كلها مجانية ومفتوحة)
| المكوّن | شغلته | اتجرب |
|---|---|---|
| **PostgreSQL 16** | القاعدة (ملفات `db/00` لـ `db/11`) | أيوه |
| **PostgREST 12** | بيحوّل القاعدة لعنوان الكاشير والبوت بيكلموه، وبيطبّق صلاحيات كل يوزر | أيوه |
| **Caddy 2** | البوابة: الشاشات + `/rest/v1` (نفس عنوان Supabase، فكود البوت شغال زي ما هو) | أيوه |
| **cloudflared** (اختياري) | نفق آمن عشان البوت والموبايل يوصلوا من برا الصيدلية، من غير فتح أي حاجة في الراوتر | لا |

**اتجرب** = على Linux بنفس النسخ (`tests/check-api.sh`). **لم يُختبر على ويندوز لسه.**

```
كمبيوتر الصيدلية
 ├─ PostgreSQL  (127.0.0.1 بس)
 ├─ PostgREST   (127.0.0.1:3000)  ← بيتأكد من مفتاح كل يوزر وصلاحياته
 └─ Caddy       (:8080 على شبكة الصيدلية)  ← الكاشير والإدارة من أي جهاز في الصيدلية
        └─ cloudflared (اختياري) ← البوت وموبايلك من برا، بيوزر ومفتاح
```

## الأجهزة
- ويندوز 10 أو 11، SSD، رام 8 جيجا.
- **UPS** عشان الكهربا.
- هارد تاني أو فلاشة للنسخ الاحتياطي.

## الخطوات
1. **PostgreSQL 16:** تسطيب عادي، والخدمة تقوم مع الويندوز، وتسمع على `127.0.0.1` بس.
2. **القاعدة:** `createdb asker`، وبعدين الملفات بالترتيب: `psql -d asker -f db\00-auth.sql` … `db\11-import.sql`.
3. **الأسرار** (بتتعمل على الجهاز ومابتطلعش منه):
   - `insert into auth.config values ('jwt_secret', '<48 حرف عشوائي>');`
   - `alter role authenticator password '<كلمة سر طويلة>';`
   - نفس القيمتين في `install\postgrest.conf`.
4. **PostgREST وCaddy** كخدمات بتقوم مع الويندوز (`install\postgrest.conf` و`install\Caddyfile`). `ASKER_BIND=0.0.0.0` عشان أجهزة الصيدلية تفتح البورت 8080، وفايروول الويندوز يسمح بيه لشبكة الصيدلية بس.
5. **أول مالك:** `select auth.bootstrap_owner('taher', '<كلمة السر>', 'د. طاهر');` (بتشتغل مرة واحدة).
6. **اليوزرات من البرنامج** بحساب المالك:
   - موظف: `ph.create_user('cashier1', '<كلمة سر>', 'اسمه', 'cashier')`.
   - البوت: `ph.create_user('bot', null, 'بوت النواقص', 'bot')`، وبعدين `ph.issue_bot_token('bot', 365)` = مفتاح بيتحط في إعدادات البوت.
   - لو المفتاح وقع في إيد حد: `ph.revoke_tokens('bot')` ← كل مفاتيحه القديمة بتقف فورًا.
7. **النقل من فارمافلاي على نفس الجهاز:** أدوات `import\` بتقرا من SQL Server بتاع فارمافلاي على طول (`MSSQL_HOST=127.0.0.1`)، وتنقل في القاعدة الجديدة. **مفيش ملف بيتنقل ولا بيترفع.**
8. **النسخ الاحتياطي:** `install\backup.ps1` كل ليلة الساعة 3 الصبح (بعد القفل) ← `D:\AskerBackups`، ونسخة كل أسبوع على الهارد التاني.
9. **البوت من برا (اختياري):** `cloudflared` بيعمل عنوان https للبوابة. البوت بيستخدم العنوان ده ومفتاح يوزر البوت. لو الكمبيوتر مقفول أو النت واقف: البوت بيقول «البرنامج مش متاح»، والكاشير شغال عادي لأنه على نفس الشبكة.

## البوت بيكلم البرنامج إزاي
- نفس مكتبة supabase-js اللي البوت بيستخدمها دلوقتي، بتغيير العنوان والمفتاح بس:
  `createClient('<عنوان البرنامج>', 'local', { db: { schema: 'ph' }, global: { headers: { Authorization: 'Bearer <مفتاح البوت>' } } })`
- يوزر البوت **يقرا:** الأصناف، الرصيد، النواقص، أحسن خصم، الموردين، الطلبيات.
- **ويكتب:** عروض الموردين من الواتس، أسماء الموردين للأصناف، «اتطلب»، كمية النواقص، صور الفواتير.
- **مالوش:** العملاء، فواتير البيع والشرا، الفلوس، ومايقدرش يبيع ولا يطلّع مفاتيح.

## الأمان
- الدخول بكلمة سر (bcrypt)، و**5 مرات غلط = الحساب يتقفل ربع ساعة**.
- مفتاح الموظف بيخلص بعد 12 ساعة. مفتاح البوت لحد سنة، ويتلغي في أي لحظة.
- القاعدة نفسها بتطبّق صلاحيات كل دور على كل جدول، مش الشاشات بس.
- PostgreSQL وPostgREST مش ظاهرين برا الجهاز. الظاهر البوابة بس.
