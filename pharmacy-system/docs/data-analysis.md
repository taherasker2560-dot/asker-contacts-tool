# تحليل الداتا اللي بُني عليها الهيكل

**اتعمل:** 11 نوفمبر 2026، قراية بس من قاعدة البوت (Supabase `asker-nawaqes`) ومن كود البوت. مفيش ولا سطر اتكتب أو اتمسح.
**مش مكتوب هنا عمدًا:** أسماء المناديب وأرقامهم، أسماء العملاء، قيمة المخزون بالفلوس. (المستودع عام.)

## الأرقام وإيه معناها للبرنامج

| اللي لقيناه | الرقم | معناه في التصميم |

| أصناف عليها وحدات فكّة دلوقتي | 885 | الكاشير بيبيع بالشريط من أول يوم، وسعر الشريط = سعر العلبة على التشغيلة ÷ عدد الشرايط. |

## جداول البوت الحالية ← مكانها في البرنامج الجديد

لحد ما البرنامج الجديد يشتغل، الجداول دي بتفضل زي ما هي. بعد التبديل البوت يقرا من القاعدة الجديدة (الجدول تحت في `README.md` ← «الربط مع شغلنا»).

| الجدول (موجود) | القسم | لحد التبديل؟ |
|---|---|---|
| `ar_shortages`, `ar_names`, `ar_answers`, `ar_fixes`, `ar_ignored` | المشتريات ← النواقص / الترجمة / الوارد | أيوه |
| `ar_inbox`, `ar_inbox_media`, `ar_inbox_keys`, `ar_suppliers` | المشتريات ← الوارد | أيوه (`ar_suppliers` = المناديب؛ `ph.supplier_reps` بيكبّرها بعدين) |
| `ar_orders` | المشتريات ← الطلبيات («اتطلب») | أيوه |
| `ar_supplier_lists`, `ar_supplier_items`, `ar_supplier_aliases` | المشتريات ← قوايم المخازن | أيوه |
| `ar_stock` | المشتريات ← المخزون + الصلاحية | أيوه |
| `ar_documents` | المشتريات ← الفواتير، الحسابات ← المصروفات | أيوه |
| `ar_store_items`, `ar_store_orders`, `ar_store_settings`, `ar_store_arabic`, `ar_store_generic` | المبيعات ← الموقع، والبحث (البديل) | أيوه |
| `ar_sync_log`, `ar_sync_keys`, `ar_sync_alerts`, `ar_refresh_requests` | الإعدادات ← الأجهزة، وشريط وقت الداتا | أيوه |

## جداول قديمة ممكن تتنضف (اقتراح بس، مااتعملش)
- بتاعة V10: `shortage_items`, `incoming_batches`, `incoming_items`, `name_aliases`, `reading_fixes`, `name_rejections`, `name_review_queue`, `shortage_availability`.
- مابقتش مستخدمة (حسب `docs/ARABIC-TRIAL.md` في البوت): `ar_shortage_names`, `ar_decisions`.
- نسخ احتياطية مؤقتة: `ar_inbox_backup_20261029`, `ar_shortages_backup_20261104`, `ar_shortages_active_before_20261030`.

أي مسح محتاج موافقتك ونسخة قبله.

## اللي ماقدرناش نشوفه (لم يُتحقق)
- داتا فارمافلاي نفسها: حسابات العملاء الآجل، أرصدة الموردين، البيع اليومي. النقل مفترض إن اللاب يقدر يقراها من نسخة فارمافلاي زي ما بيقرا المخزون. **ده محتاج يتأكد على اللاب قبل النقل** (`docs/migration.md`).
- عدد الموظفين ومين بيعمل إيه.
