# دليل الاختصارات: البرنامج كله من غير ماوس

**الفكرة:** أي حاجة في البرنامج بتتعمل من الكيبورد. والمفاتيح بتتقري **بمكانها على الكيبورد**، فبتشتغل والكيبورد عربي أو إنجليزي من غير ما تحوّل.
وفي البرنامج نفسه: **`F1`** بيفتح الدليل ده للشاشة اللي إنت فيها، وزرار «اطبع الدليل كله» بيطلّع ورقة A4 تتعلق جنب الكاونتر.

**مش لاقي اختصار لزرار؟** اضغط **`F4`**: بيظهر حرف على كل حاجة تتداس في الشاشة، تكتب الحرف والزرار يتداس. يعني مفيش حاجة في البرنامج محتاجة ماوس، حتى في الشاشات اللي هتتعمل بعدين.

## في كل الشاشات
| المفتاح | بيعمل إيه |
|---|---|
| `F1` أو `?` | دليل الاختصارات للشاشة دي |
| `F2` | البيع / فاتورة جديدة |
| `F3` أو `Ctrl+K` | دوّر على أي حاجة: صنف (برصيده وسعره)، عميل، أو أمر (خروج، ليلي، جهّز الطلبيات…) |
| `F4` | وضع الحروف: حرف على كل زرار |
| `F5` | حدّث البيانات من غير ما يضيع حاجة (الفاتورة اللي مفتوحة بتفضل زي ما هي) |
| `Alt+1` … `Alt+9` | الشاشات بالترتيب: 1 اللوحة، 2 البيع، 3 الأصناف، 4 الصلاحية، 5 الطلبيات، 6 العملاء، 7 الموردين، 8 التقارير، 9 الإعدادات (الرقم مكتوب جنب كل شاشة في القايمة) |
| `Alt+N` | سجّل ملاحظة في التجربة |
| `Alt+T` | نهاري / ليلي |
| `Esc` | رجوع خطوة: يمسح البحث، يلغي الاختيار، يقفل النافذة، أو يرجع من صفحة الصنف/العميل للقايمة |

## أي قايمة أو جدول (الأصناف، العملاء، الطلبيات، التقارير، الإعدادات…)
| المفتاح | بيعمل إيه |
|---|---|
| `↓` `↑` | اختار الصف اللي بعده / قبله (ومن خانة البحث `↓` بينزل على القايمة) |
| `Home` `End` `PgDn` `PgUp` | أول / آخر / نزّل 10 / طلّع 10 |
| `Enter` | افتح الصف المختار |
| `/` | خانة البحث |
| `]` `[` | التاب اللي بعده / قبله |
| `Shift+]` `Shift+[` | الفترة اللي بعدها / قبلها (التقارير) |
| `+` `−` | زوّد / قلّل الكمية في الصف المختار (الطلبيات) |
| `Del` | شيل الصف المختار (لو ينفع) |
| **حرف** | الزرار اللي جنبه الحرف ده في الصف المختار (مكتوب على الزرار) |

الحروف في كل شاشة:
| الشاشة | الحروف |
|---|---|
| العملاء: مواعيد الصرف | `W` فكّره على واتساب، `C` انسخ الرسالة، `Enter` صفحة العميل |
| العملاء: اقتراحات مزمن | `A` سجّله مزمن |
| العملاء: المديونيات | `P` حصّل منه |
| صفحة العميل | `Alt+P` حصّل، `Alt+W` واتساب، `Esc` رجوع |
| الطلبيات | `+` `−` الكمية، `Del` مش دلوقتي، `M` اتطلبت، `C` انسخ الرسالة، `W` واتساب، `Alt+R` تحديث |
| الصلاحية | `Enter` الصنف، وفي كارت المرتجع: `C` انسخ، `W` واتساب |
| التقارير | `]` `[` التابات السبعة، `Shift+]` `Shift+[` الفترة، `X` نزّل الجدول اللي فيه الصف المختار Excel، `Alt+M` ملخص الصبح، `W` «وحشتنا» لعميل بطّل ييجي |
| صفحة الصنف | `Alt+S` بيع، `Esc` رجوع |
| صفحة المورد | `Alt+P` دفع، `Esc` رجوع |
| الإعدادات | `Alt+H` افحص القاعدة، `F` الملاحظة اتصلحت، `K` مفتاح جديد للبوت، `W` كلمة سر، `L` اقفل جلساته، `Alt+A` موظف جديد، `Alt+S` احفظ |

## البيع
| المفتاح | بيعمل إيه |
|---|---|
| `F2` | خانة البحث |
| باركود ← `Enter` | الصنف في الفاتورة (بصوت). `3*` قبل الباركود = 3 علب |
| اسم ← `↓` `↑` ← `Enter` | اختار من النتايج |
| `Alt+B` | بدايل الصنف اللي عليه الاختيار في النتايج |
| `↓` `↑` (والبحث فاضي) | اختار صنف في الفاتورة |
| `+` `−` | كمية الصنف المختار (أو آخر صنف) |
| `*` | علبة ↔ شريط |
| `Del` | شيل الصنف المختار |
| `Alt+C` | العميل (`↓` `↑` `Enter` للاختيار) |
| `Alt+X` | الخصم |
| `F8` `F9` `F10` `Shift+F8` | كاش / آجل / فيزا / محفظة |
| `Alt+R` ← المبلغ ← `Enter` | المستلم من العميل والباقي، وEnter بيخلّص |
| `Ctrl+Enter` | خلّص الفاتورة |
| `Enter` / `P` (في الإيصال) | فاتورة جديدة / اطبع |
| `Alt+P` أو `F6` | علّق الفاتورة (العميل بيدوّر على حاجة) |
| `Alt+Shift+P` | رجّع آخر فاتورة معلّقة |
| `Alt+L` | اطبع آخر فاتورة تاني |
| `Alt+O` | فتح / قفل الوردية |

## النوافذ
`Enter` من أي خانة = الزرار الأساسي (سجّل، احفظ، حصّل…)، و`Ctrl+Enter` من خانة الكتابة الكبيرة، و`Esc` يقفل. الاختيارات زي نوع الملاحظة: `←` `→`.

## ليه مفيش `F6` و`F7` و`F11` و`F12` لأوامر مهمة
المتصفح بياخدهم قبل البرنامج (`F11` ملء الشاشة، `F12` أدوات المطوّر، `F7` و`F6` في بعض المتصفحات). عشان كده **أيقونة «صيدلية عسكر»** على سطح المكتب بتفتح البرنامج في نافذة لوحده (Edge أو Chrome كتطبيق) من غير شريط عنوان، و**`Ctrl+Alt+A`** بيفتحه من أي مكان في الويندوز. التفاصيل في [`install/laptop/README.md`](../install/laptop/README.md#أيقونة-على-سطح-المكتب).

## اختصارات فارمافلاي
دليل اختصارات فارمافلاي **مش عندي في الملفات اللي أقدر أوصلها**. الاختصارات كلها مكتوبة في جدول واحد (`KEYS` في `app/assets/kbd.js`، ومفاتيح البيع في `POS_KEYS`). أول ما تبعت الدليل (صورة أو PDF)، هعمل نسخة «زي فارمافلاي»: نفس المفاتيح اللي إيدك متعودة عليها للأوامر المشتركة، وفوقها الزيادات دي.
