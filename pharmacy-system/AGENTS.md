# قواعد التعديل على برنامج صيدلية عسكر

قواعد المالك العامة في `AGENTS.md` بتاع مستودع البوت (asker-nawaqes) سارية هنا كمان: الالتزام بالمطلوب، فحص الوضع الحالي، تعديلات صغيرة قابلة للرجوع، اختبار قبل «شغال»، السلامة، خطوة واحدة في كل مرة، وجدول التقرير. القواعد دي زيادة عليها للبرنامج ده. شرحها للمالك في `docs/changes.md`.

## 1) القاعدة
1. ملفات `db/00` لـ `db/13` = التسطيب الأول. **بعد التسطيب على اللاب ماتتعدلش.** أي تعديل = ملف جديد في `db/migrations` (القواعد في `db/migrations/README.md`).
2. ماتعدّلش ملف تعديل اتطبق. البصمة متسجلة والتحديث بيوقف.
3. الدفاتر (`stock_moves`، `money_moves`، `party_ledger`) والمستندات المرحّلة ماتتعدلش ولا تتمسح. الغلط بمستند عكسي.
4. مفيش مسح داتا ولا `drop` لجدول فيه داتا من غير موافقة المالك الصريحة ونسخة احتياطية.
5. أي كتابة في الفلوس أو المخزون من دالة ترحيل (`post_*`)، وأي دور جديد له صلاحيات في `10-security.sql` أو في ملف تعديل.

## 2) الاختبارات (لازم كلها تعدّي قبل التسليم)
```
bash tests/check-db.sh          # يوم شغل كامل + الصلاحيات + الفحص الذاتي
bash tests/check-import.sh      # النقل من فارمافلاي
bash tests/check-migrate.sh     # طريقة التعديل
bash tests/check-concurrency.sh # كاشيرين على آخر علبة
bash tests/soak.sh              # الضغط
bash tests/check-restore.sh     # النسخة الاحتياطية
bash tests/check-api.sh         # الدخول والبوت عن طريق HTTP (محتاج Docker)
bash tests/check-pipeline.sh    # فك ونقل نسخة SQL Server (محتاج Docker)
node tests/check-app.cjs        # الشاشات
```
- كل تعديل معاه اختبار جديد يثبته، وحالة فشل لو ليها معنى.
- لو اختبار ماتشغّلش، قول «لم يُختبر» وليه.

## 3) اللاب (التجربة)
- التحديث: `install/laptop/update-trial.ps1`. الرجوع: `install/laptop/rollback-trial.ps1 -Commit <الرقم اللي التحديث طبعه>`.
- سكريبتات ويندوز: UTF-8 بعلامة BOM (عشان العربي في PowerShell 5.1)، وأي خطوة ماتجربتش على ويندوز تتقال صراحة.
- المشاكل اللي بتظهر في التجربة تتسجل في `ph.trial_notes`، والمقفولة يتكتب جنبها اتصلحت في أنهي تعديل.

## 4) الداتا
- ممنوع أي داتا من الصيدلية في GitHub: نسخ فارمافلاي، `discovery.*`، الأسرار، التقارير. (`.gitignore` بيمنع أشهرها، والمسؤولية عليك.)
- الأسرار (`auth.config`، كلمات السر) على الجهاز بس.
